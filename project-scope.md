## Task

Build a Single Page Application for tasks management using modern technologies. No database - backend is only an imitation. This is just a test exercise.

## Features

- Main page contains a list of tasks
- A task should look like a card with the following properties: title, description, status, priority, deadline, tags
- User can create a task using modal window
- Overdue tasks should be highlighted
- Possibility to quickly change status (dropdown)
- Click on the card opens the card page with details
- Click on the tag filters tasks by this tag
- User can create new tags and add them to the task

## Task Statuses

- **TODO** — newly created task
- **In Progress** — currently executing task
- **Done** — task is fulfilled
